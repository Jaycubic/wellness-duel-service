Rule Book

Step & Share is a live wellness duel. Everyone in a room shares the same real-time board, hosted on a server that keeps score honestly.

Players

Up to a handful of friends per room, each on their own device, connected over the same network.

Goals

Reach the room's point target, or have the most points when the 7-day week ends.

Rules

Each real calendar day, pick one activity and mark it Done (earns points, streak +1) or Skip (streak resets). Repeating yesterday's activity earns reduced points, so mixing it up pays off. A proof photo is optional. The server — not your device — decides your points, so nobody can fake a score.

Space

Physical space is wherever you do the activity. Digital space is this shared room, live for everyone connected.

Time

One round equals one real day, tied to the room's creation date — not a button you can click through.

Resources

A fixed set of 10 emoji represents every activity, plus fire, trophy, and celebration.

Conflict

Everyone races toward the same target on the same live board — a real duel, not a snapshot.
